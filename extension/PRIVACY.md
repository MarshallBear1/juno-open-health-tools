# Privacy notice — Juno Appointment Prep extension

Effective date: 1 August 2026

## Data handled

The extension lets a user enter an appointment date, clinician or service, a main goal, symptom observations, timeline notes, daily-life impacts, and questions.

## Where data is stored

Version 1.0.0 stores this information only in the browser's local extension storage on the user's device. It does not transmit those notes to Juno, an analytics service, an advertising service, or another remote server. The user can copy a summary, download a text file, or clear the stored notes.

## Permissions

The extension requests the Chrome `storage` permission solely to retain the user's appointment-preparation notes between popup sessions.

## External links

The extension contains optional links to Juno, GitHub, and Zenodo. Opening a link is a user-initiated navigation governed by that site's privacy practices. The Juno link contains campaign parameters so visits from the extension can be distinguished in aggregate web analytics; no health-note content is added to the link.

## Health and safety scope

This extension organises user-supplied observations and questions. It does not diagnose, recommend treatment, replace professional care, or provide emergency support. Users should avoid recording information they do not want stored in their browser profile.
